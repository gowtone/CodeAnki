# ①課題名
プログラミング暗記帳

## ②課題内容（どんな作品か）
- プログラミングの文法や命令を覚えるための暗記カードアプリです。
- ジャンル（HTML / CSS / JavaScript / jQuery）・問題・答えを入力してカードを登録できます。
- 登録したカードは localStorage に保存されるので、ブラウザを閉じても消えません。
- ジャンルで絞り込むと、そのジャンルのカードだけを一覧表示します。
- 「出題する」で、絞り込んだカードの中からランダムに1枚出題し、「答えを見る」で答えを表示します。
- カードは1枚ずつ編集・削除できます。

## ⑤工夫した点・こだわった点
- 講義の「メモ帳」をそのまま作るのではなく、今まさに勉強しているプログラミングの命令を覚えるための暗記帳にした。作ったアプリで、そのまま今回の講義内容を復習できる
- カード1枚を「ジャンル・問題・答え」のオブジェクトにまとめて配列に入れ、`JSON.stringify()` / `JSON.parse()` で localStorage に保存・読み込みした
- 答えに `<ul>` のようなタグを書いても消えないように、入力された文字は `.text()` で表示した
- 答えは `<details>` を使い、押したときだけ開くようにして、一覧を見ながらでも暗記の練習ができるようにした
- `Math.random()` で、絞り込んだジャンルの中からランダムに出題するようにした
- 講義の「全削除ボタン」は暗記帳では使い道が少ないと考えてやめ、代わりに1枚ずつの編集・削除を付けた。削除するときは確認を出すようにした

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 難しかった点：localStorage を使ったアプリを、ただのメモ帳ではない形にするアイデアを考えること
- 難しかった点：作ってから「全削除は実際には使わない」「間違えて登録したカードを直せない」と気づき、使う人の目線で機能を見直すこと
- 難しかった点：HTMLやjQueryの短い1行の中に、いくつもの指示（タグ・属性・id・class・命令のつなぎ方）が詰まっていて、1つずつ分解しないと何をしているのか分かりにくかった
- 次回トライしたいこと：覚えたカード・覚えていないカードを記録して、覚えていないカードを多めに出題する
- 次回トライしたいこと：Ankiのように、次に復習する日を自動で決める機能
- 次回トライしたいこと：キーワードでカードを検索する機能
